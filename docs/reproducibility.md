# Reproducibility scope

The release supports three distinct levels of reproducibility.

## 1. Released-artifact verification — self-contained

The repository includes:

- the 168,363-observation final benchmark index;
- frozen query and nested support memberships;
- the three selected genome feature matrices;
- all final molecular feature matrices;
- target-excluded configurations and numerical hyperparameters;
- single-source and multi-source run plans;
- final training, adaptation, aggregation, and metric code;
- aggregate model-selection and held-out evaluation tables.

After installing the dependencies, run:

```bash
python scripts/verify_release.py
python scripts/verify_release.py --full
```

The first command validates the benchmark, matrices, row mappings, split
leakage, nested support sets, configurations, results, documentation, and
Python syntax. The second additionally imports the frozen model stack and
performs one CPU forward pass for each outer-target configuration.

## 2. Frozen final-evaluation training — reproducible from released matrices

The released feature matrices, configurations, run plans, and split
memberships support rerunning the frozen final evaluation.

The final entry points are:

```bash
python scripts/train_zero_target.py --device cuda
python scripts/aggregate_zero_target.py

python scripts/adapt_random_pair.py --device cuda
python scripts/aggregate_random_pair.py

python scripts/adapt_genome_disjoint.py --device cuda
python scripts/aggregate_genome_disjoint.py

python scripts/adapt_antibiotic_held_out.py --device cuda
python scripts/aggregate_antibiotic_held_out.py
```

The three adaptation stages require the source checkpoints generated by
`train_zero_target.py`.

## 3. Reconstruction from raw public resources — partially documented and not self-contained

Raw [BV-BRC](https://www.bv-brc.org/) downloads, genome assemblies, discarded
candidate feature matrices, source checkpoints, per-run predictions, and
training histories are not stored in Git.

The numbered scripts preserve the released benchmark-curation,
species-verification, AMR-feature, model-selection, and split-freezing audit
trail. They are not one uninterrupted raw-to-results command chain. Some
scripts consume frozen historical manifests or candidate assets whose
generating steps are not included in the public release.

Raw reconstruction requires:

- fresh BV-BRC records and genome assemblies;
- the Python packages pinned in
  [`../requirements.txt`](../requirements.txt);
- separately installed
  [Kleborate](https://github.com/klebgenomics/Kleborate);
- separately installed
  [AMRFinderPlus](https://github.com/ncbi/amr);
- external molecular resources;
- regeneration of historical intermediate assets that are not distributed.

The molecular-feature provenance included in this release comprises:

- the frozen ChemBERTa model and revision specification in
  [`../metadata/drug_representation/chemberta_checkpoint_spec.tsv`](../metadata/drug_representation/chemberta_checkpoint_spec.tsv);
- the ordered 27-descriptor RDKit schema in
  [`../metadata/drug_representation/rdkit_descriptor_columns_v1.tsv`](../metadata/drug_representation/rdkit_descriptor_columns_v1.tsv);
- the molecular-feature generation protocol in
  [`../metadata/drug_representation/drug_feature_generation_protocol_v1.tsv`](../metadata/drug_representation/drug_feature_generation_protocol_v1.tsv).

Because BV-BRC is a live resource, a fresh download may not be byte-identical
to the 22 July 2026 snapshot. The released observation index, feature
matrices, split definitions, configurations, and aggregate tables are
therefore the authoritative paper artifact.

## Path portability

The supported final-evaluation entry points use repository-relative paths and
honour `MIC_TRANSFER_PROJECT` when the project root is supplied explicitly.

Some historical configuration-selection scripts retain legacy
machine-specific fallback paths. When running those scripts, set the project
root before execution:

```bash
export MIC_TRANSFER_PROJECT="$(pwd)"
```

These historical fallbacks are retained to avoid changing frozen
configuration-selection scripts and their provenance. Gzip-compressed TSV
files are read directly by pandas.
